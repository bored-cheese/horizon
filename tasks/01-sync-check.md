# Задача 1. Сверка доски с реестром

**Пишет на доску:** нет. Только читает и докладывает.
**Периодичность:** раз в неделю, по расписанию.

## Что сделать

Сверь фрейм «Горизонт планирования» с таблицей «Реестр потребностей»
на доске Miro, указанной в инструкциях проекта.

Доложи расхождения пятью списками:
1. Стикеры без ID в тексте.
2. ID на доске, которым нет строки в таблице.
3. Строки таблицы, которым нет стикера на доске.
4. Строки, где цвет стикера не совпадает с `importance`
   или годовая полоса не совпадает с `period`.

## Ограничения
Ничего не исправляй. Эта задача только докладывает.
Соответствие цвета и важности: красный — критично, оранжевый — важно,
светло-жёлтый — база, зелёный — мечта, синий — совсем мечта (ваниль).
