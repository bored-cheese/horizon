# Задача 1. Сверка доски с реестром

> Требует инструкций проекта «Горизонт»: разделы «Геометрия фрейма»
> и «Разделение владения». Вне проекта задача работать не будет.

**Пишет на доску:** нет.
**Пишет в таблицу:** нет. Только читает и докладывает.

## Что прочитать

С доски — стикеры внутри фрейма «Горизонт планирования» и линии между ними.
Разметку не вычитывай.

Из таблицы «Реестр потребностей» — все строки.

Стикеры за пределами фрейма не трогай: над ним лежит запас пустых заготовок. Стикеры без текста пропускай, даже если они внутри фрейма.

## Что доложить

Шесть списков:

1. Стикеры без ID в тексте.
2. ID на доске, которым нет строки в таблице.
3. Строки таблицы, которым нет стикера на доске.
4. Строки, где цвет стикера не совпадает с `importance`, дорожка не совпадает с `type`, или вычисленный год не совпадает с `period`.
5. Линии между стикерами: где связь не отражена в `depends on` или `p_id`, где нижний по времени зависит от верхнего, и где направление не определилось.
6. Строки без тэгов.

Дополнительно отметь ячейки, в которых вместо значения лежит служебная
обёртка формата.

## Ограничения

Ничего не исправляй. Эта задача только докладывает.
